# T.I.P.E

Ce dépôt est prêt à être rempli avec les fichiers de ton projet T.I.P.E.

## Structure proposée

- `/codes/` : tes 3 fichiers Python (`.py`)
- `/video/` : la vidéo de démonstration (`.mp4`)
- `/rapport/` : ton document Word (`.docx`)

## Étapes

1. Copie tes trois scripts Python dans `/codes/`
2. Copie ta vidéo `.mp4` dans `/video/`
3. Copie ton fichier Word dans `/rapport/`
4. Commit/push les fichiers

Tu peux aussi renommer les fichiers selon des noms explicites (exemple : `simulation.py`, `analyse.py`, `presentation.docx`).
